# 45 DAYS — Class 10 CBSE Study Planner v0.2.0

Offline-first Android study planner for Class 10 CBSE students. No login and no AI dependency.

## Included in v0.2
- First-run study setup
- 45-day local planning
- Today dashboard with daily workload
- Local syllabus/topic dataset for Mathematics, Science, Social Science, English and Hindi B
- Topic guide cards
- Completion tracking
- Subject progress
- Daily reminder notification
- Java/Kotlin JVM 17 compatibility
- GitHub Actions debug APK build

## Important curriculum note
CBSE publishes the current Class X curriculum and sample papers for each academic session. This starter dataset is structured around the current 2026–27 Class X subject set, but a production release should verify every chapter/topic against the official CBSE and NCERT documents before publication.

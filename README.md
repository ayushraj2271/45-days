# 45 DAYS — Class 10 CBSE Study Planner

Native Android starter for an offline-first Class 10 CBSE study planner.

## Current version
0.1.0

## Included
- Offline local syllabus dataset
- First-run study setup
- Preparation duration
- Available study hours
- Exam-date field
- Today dashboard
- Day calendar
- Topic completion
- Progress tracking
- Study thoughts
- GitHub Actions APK build

## Build
Use GitHub Actions → Build 45 Days APK → Run workflow.

## Important
The syllabus data is designed around the official CBSE 2026–27 curriculum structure. Before publishing a final production build, expand and verify every course-specific chapter/topic dataset against the official CBSE/NCERT documents.
